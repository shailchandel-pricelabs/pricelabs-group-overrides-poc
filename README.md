# Group Overrides POC

A static HTML prototype of the "view all date-specific overrides" feature for the Dynamic Pricing Customization page — not just the most recent 100. Built from the PRD discussion in Slack thread `C06C91TKMLG/p1788251570550159`.

Demonstrates: a preset date-range dropdown (Most Recent 100 / Starting within 1, 6, 12 months / All overrides), a real per-page selector (25/50/100/500), a right-aligned pager, a dedicated loading state for the "All overrides" case, and CSV upload/download CTAs with busy-state + toast feedback.

Open `index.html` directly in a browser, or deploy as-is — no build step required.
